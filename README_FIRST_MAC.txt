ScoreCapture macOS 처음 실행

이 안내문은 배포 파일 안에 들어 있습니다.
같은 폴더에 있는 ScoreCapture.app을 실행하세요.

1. ScoreCapture.app을 실행하세요.
2. 화면 기록 권한을 묻거나 설정이 열리면 ScoreCapture를 허용하세요.
3. 권한을 허용한 뒤 ScoreCapture를 완전히 종료하고 다시 실행하세요.
4. PDF는 문서/Documents 폴더 안의 ScoreCapture 폴더에 저장됩니다.

macOS가 "확인되지 않은 개발자"라고 막으면:
ScoreCapture.app을 Control 키를 누른 채 클릭하고, 열기 > 열기를 선택하세요.
