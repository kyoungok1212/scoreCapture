ScoreCapture 사용 가이드

이 문서는 Mac에서 ScoreCapture를 처음 실행하는 분을 위한 안내입니다.


1. 받은 파일 확인

전달받은 파일 이름은 보통 아래와 같습니다.

ScoreCapture-macOS.dmg

이 파일 하나만 있으면 됩니다.


2. 앱 열기

1) ScoreCapture-macOS.dmg 파일을 더블클릭합니다.
2) 새 창이 열리면 그 안에 있는 ScoreCapture.app을 더블클릭합니다.


3. "확인되지 않은 개발자"라고 나올 때

Mac 보안 때문에 처음 실행할 때 막힐 수 있습니다.
이 경우 아래 순서대로 실행하세요.

1) ScoreCapture.app을 그냥 더블클릭하지 않습니다.
2) 키보드의 Control 키를 누른 채 ScoreCapture.app을 클릭합니다.
3) 메뉴에서 "열기"를 누릅니다.
4) 다시 확인 창이 나오면 "열기"를 누릅니다.

이 과정은 보통 처음 한 번만 하면 됩니다.


4. 화면 기록 권한 허용

ScoreCapture는 화면에 보이는 악보를 캡처하는 앱이라 화면 기록 권한이 필요합니다.

앱에서 권한 안내가 나오면:

1) 설정 열기를 누릅니다.
2) 시스템 설정에서 ScoreCapture를 허용합니다.
3) ScoreCapture를 완전히 종료합니다.
4) ScoreCapture를 다시 실행합니다.

권한을 허용했는데도 안 되면 Mac을 한 번 재시동한 뒤 다시 실행해보세요.


5. 사용 방법

1) ScoreCapture.app을 실행합니다.
2) "1. 캡처 영역 선택"을 누릅니다.
3) 악보가 보이는 전체 영역을 마우스로 드래그합니다.
4) "2. 캡처 시작"을 누릅니다.
5) 악보 페이지를 넘기면 앱이 변화된 화면을 자동으로 캡처합니다.
6) 끝나면 "종료 및 PDF 생성"을 누릅니다.


6. PDF 저장 위치

완성된 PDF는 아래 위치에 저장됩니다.

문서 > ScoreCapture

파일 이름은 아래와 같습니다.

final_sheet_music_stitched.pdf


7. 자주 막히는 부분

앱이 화면을 못 읽는다고 나올 때:
화면 기록 권한을 허용한 뒤 앱을 완전히 종료하고 다시 실행하세요.

PDF가 생성되지 않을 때:
캡처된 이미지가 하나도 없으면 PDF가 만들어지지 않습니다.
먼저 캡처 영역을 선택하고 캡처 시작을 누른 뒤 악보 화면을 넘겨주세요.

앱을 다시 찾고 싶을 때:
DMG 안의 ScoreCapture.app을 응용 프로그램 폴더로 드래그해서 옮겨두면 다음부터 찾기 쉽습니다.
